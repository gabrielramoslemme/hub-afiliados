# 1.5 — Modelo de dados e ambiente local

| | |
|---|---|
| **Tipo** | Task |
| **Card pai** | Configuração dos projetos |
| **Épico** | SIS-508 — Hub de Afiliados |
| **Depende de** | 1.2 |

## Descrição

Modelar e criar as informações que a Onda 1 precisa guardar: as pessoas que acessam o sistema — afiliados e operadores da Porto —, os dados de cadastro do afiliado, o registro do aceite dos termos, o histórico de todas as mudanças de situação do cadastro e o controle dos links de senha e das sessões abertas.

Afiliados e operadores compartilham o mesmo registro de identidade, com os dados específicos de cada tipo guardados à parte. Isso evita escrever e manter duas vezes tudo o que é comum a quem acessa o sistema — senha, recuperação, sessão — e permite que a mesma pessoa seja operadora e afiliada, o que acontece já nos testes de homologação.

O histórico de mudanças de situação nasce aqui e é o que sustenta a exigência de trilha auditável do programa: quem decidiu, quando e por quê. Ele nunca é editado nem apagado.

Também entra a base de dados local subindo por comando, e o carregamento inicial dos operadores do painel e da versão vigente dos termos.

## Critérios de aceite

- [ ] Um comando cria e atualiza a estrutura da base de dados, sem passo manual.
- [ ] Toda atualização de estrutura pode ser desfeita por comando.
- [ ] Afiliados e operadores compartilham o mesmo registro de identidade, com dados específicos separados por tipo.
- [ ] A base recusa, por si só, um cadastro reprovado sem motivo registrado.
- [ ] E-mail e CPF são únicos no sistema.
- [ ] Toda mudança de situação de um cadastro fica registrada com origem, destino, autor, data e motivo.
- [ ] Um comando carrega os operadores iniciais do painel e a versão vigente dos termos.
- [ ] A base de dados local sobe por comando, sem instalação manual de banco.

## Objetivo

Ter as informações da Onda 1 modeladas e o ambiente local reproduzível, para que as funcionalidades de cadastro, acesso e aprovação sejam construídas sobre uma base consistente e auditável.

## Job Story

Quando eu começo a trabalhar no projeto, eu quero subir a base de dados e carregar os dados iniciais com um comando, para começar a desenvolver em minutos e não em horas.
