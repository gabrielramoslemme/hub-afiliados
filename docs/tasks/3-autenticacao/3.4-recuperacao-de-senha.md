# 3.4 — Recuperação de senha

## Descrição

Afiliados e operadores da Porto esquecem senha. Este card entrega o caminho de recuperação para os dois públicos: a pessoa informa o e-mail, recebe um link e define uma senha nova.

Uma decisão importante de segurança: a tela responde a mesma coisa exista ou não uma conta com aquele e-mail. Se respondesse diferente, qualquer pessoa poderia usar a tela para descobrir quem faz parte do programa — e a base de afiliados da Porto é informação de negócio.

O link de recuperação tem validade curta e serve uma única vez. Pedir um link novo invalida o anterior, para que nunca existam dois links válidos ao mesmo tempo. Redefinir a senha encerra todas as sessões abertas daquela conta.

## Critérios de aceite

- [ ] O afiliado consegue pedir recuperação de senha pelo aplicativo.
- [ ] O operador consegue pedir recuperação de senha pelo painel.
- [ ] A resposta na tela é idêntica exista ou não conta com aquele e-mail.
- [ ] Nenhum e-mail é enviado quando não existe conta com aquele endereço.
- [ ] O link de recuperação tem validade curta e serve uma única vez.
- [ ] Pedir um link novo invalida o anterior.
- [ ] Definir a senha nova encerra todas as sessões abertas daquela conta.
- [ ] Depois da redefinição, a senha antiga deixa de funcionar e a nova funciona.
- [ ] Tentativas repetidas de pedido a partir da mesma origem são bloqueadas temporariamente.

## Objetivo

Permitir que afiliados e operadores recuperem o acesso sozinhos, sem acionar suporte, e sem que a tela de recuperação vire uma forma de descobrir quem participa do programa.

## Job Story

Quando eu esqueço minha senha, eu quero recuperar o acesso informando meu e-mail, para voltar a usar o sistema sem precisar falar com o suporte.
