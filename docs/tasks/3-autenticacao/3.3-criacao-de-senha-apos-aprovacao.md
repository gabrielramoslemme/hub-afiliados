# 3.3 — Criação de senha após a aprovação

| | |
|---|---|
| **Tipo** | Story |
| **Card pai** | Autenticação |
| **Épico** | SIS-508 — Hub de Afiliados |
| **Issue existente** | SIS-511 |
| **Depende de** | 3.1, 1.6 |

## Descrição

O cadastro do afiliado não pede senha — é um pré-cadastro. A senha entra na jornada no momento em que a Porto aprova o perfil: junto com o e-mail de boas-vindas, o afiliado recebe um link para criar sua senha e, a partir dali, entrar no aplicativo.

O link tem validade e serve uma única vez. Quem já usou o link e tenta usá-lo de novo recebe orientação para solicitar um novo — o mesmo caminho de quem deixou o prazo passar.

Ao criar a senha, qualquer sessão anterior daquela conta é encerrada. É a proteção que faz diferença no cenário em que o link foi interceptado: quem o usou primeiro é desconectado assim que o dono legítimo cria a sua senha.

## Critérios de aceite

- [ ] O e-mail de aprovação traz um link para criação de senha.
- [ ] O link tem prazo de validade definido e comunicado ao afiliado.
- [ ] O link serve uma única vez.
- [ ] Um link já usado ou vencido mostra mensagem clara com orientação para solicitar outro.
- [ ] A senha exige um mínimo de caracteres, com ao menos uma letra e um número.
- [ ] Depois de criar a senha, o afiliado entra no aplicativo normalmente.
- [ ] Criar a senha encerra qualquer sessão anterior daquela conta.
- [ ] O afiliado consegue solicitar o reenvio do link pela tela de login.

## Objetivo

Permitir que o afiliado aprovado crie sua senha com segurança e comece a usar o aplicativo, sem que a senha precise existir antes de haver decisão sobre o cadastro.

## Job Story

Quando meu cadastro é aprovado, eu quero criar minha senha pelo link que recebi por e-mail, para entrar no aplicativo e começar a divulgar meu cupom.
